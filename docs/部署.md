1. 在项目根目录
   - 启动项目：docker compose up -d --build
   - 查看日志：docker compose logs -f web
   - 看数据库日志：docker compose logs -f db
   - 重启项目：docker compose restart
   - 完整的构建：
     docker compose down
     docker compose up -d --build
   - 测试部署是否成功
     - 访问 http://127.0.0.1:3000，应该能够看到项目运行的界面
   - 数据备份
     docker exec spring-todo-db pg_dump -U postgres todolist > /srv/todolist/todolist-backup.sql
2. 导出数据库
   - docker exec spring-todo-db pg_dump -U postgres todolist > /srv/data/todolist-backup-$(date +%Y%m%d).sql

3. 设置定时任务备份
   - 创建备份脚本 - 编辑 /srv/todolist/backup.sh - 添加以下内容：

     ```
     #!/bin/bash
      set -e
      DATE=$(date +%Y%m%d\_%H%M%S)
      BACKUP_DIR=/srv/todolist/backups
      KEEP_DAYS=7
      CONTAINER_NAME=spring-todo-db
      DB_NAME=todolist
      DB_USER=postgres
      LOG_FILE=/srv/todolist/backups/backup.log

      mkdir -p ${BACKUP_DIR}

      echo "[$(date)] 开始备份数据库..." >> ${LOG_FILE}

      docker exec ${CONTAINER_NAME} pg_dump -U ${DB_USER} -d ${DB_NAME} -F c -b > ${BACKUP_DIR}/todolist-${DATE}.dump

      BACKUP_SIZE=$(du -h ${BACKUP_DIR}/todolist-${DATE}.dump | cut -f1)
      echo "[$(date)] 备份完成，文件: todolist-${DATE}.dump，大小: ${BACKUP_SIZE}" >> ${LOG_FILE}

      find ${BACKUP_DIR} -name "todolist-*.dump" -mtime +${KEEP_DAYS} -delete
      echo "[$(date)] 清理旧备份完成，保留最近 ${KEEP_DAYS} 天" >> ${LOG_FILE}
     ```

- 给备份脚本添加执行权限：chmod +x /srv/todolist/backup.sh
- 配置 crontab 定时任务，每天凌晨 1 点执行备份操作
  - 编辑 crontab 任务：crontab -e
  - 添加以下行：
    ```
    0 3 \* \* \* /srv/todolist/backup.sh >> /srv/todolist/backups/backup.log 2>&1
    ```
    （表示每天凌晨 3 点自动执行）
- 查看备份日志
  tail -f /srv/todolist/backups/backup.log
